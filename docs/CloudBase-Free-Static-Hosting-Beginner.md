# CloudBase 免费静态网站上线：Agent 新手教程

适用于纯静态网站：HTML、CSS、JavaScript、图片、字体和视频。目标是让没有编程经验的用户，通过一句自然语言指令让已授权 Agent 完成上线；用户不需要打开终端、复制命令或手动上传文件。

不适用于需要服务器端登录、数据库、支付或实时后端的网站。遇到这些能力时，Agent 必须先核对成本与资源类型；任何页面要求付费、充值、购买域名或开启按量计费，立即停止并报告。

## 你只要对 Agent 说

> 把当前网站更新并发布到原来的 CloudBase 网址。全程保持 0 元；完成后分别告诉我本地修改、发布副本、文件部署、线上验证的状态，以及网址和版本哈希。

## 第一次使用：你只做两件事

1. 登录腾讯云，在 CloudBase 控制台确认环境是 `0 元/月` 的免费体验版，且没有按量计费。
2. Agent 请求浏览器授权时，登录腾讯云并点击授权。

不要把密码、验证码、密钥或身份证明发给 Agent。若页面显示付费、充值、购买域名或按量计费，不要确认，直接把截图发给 Agent。

## Agent 必须完成的发布闭环

1. 找到网站正式主源，检查公开范围、首页、图片、样式、脚本和链接。
2. 在项目外生成隔离发布副本；不得直接上传开发目录。
3. 运行本地检查。检查失败时停止，不能部署。
4. 复核免费环境和固定发布路径；不得创建付费资源。
5. 上传受管发布副本，并保留上一版可重新部署的产物。
6. 重新读取线上文件，逐个核对 HTTP 状态、字节或版本哈希。
7. 生成回执，严格区分以下四种状态。

| 状态 | 含义 |
| --- | --- |
| 本地修改成功 | 正式网站主源已更新并通过本地检查。 |
| 发布副本生成成功 | 项目外隔离目录已生成，文件和链接已检查。 |
| 文件部署成功 | 文件已真实上传到 CloudBase。 |
| 线上网址验证成功 | 线上文件与本地发布副本一致。 |

任一项失败，都不能说“已上线”。

## 让网站打开更快

大图片、背景视频和长文档不应塞进首页 HTML。推荐把它们作为受管静态资源：

- 首页只保留首屏必须内容和轻量静态背景；优先使用 WebP。
- 视频使用 `preload="none"`，在页面加载完成后的空闲时间再加载；系统减少动态效果时不请求视频。
- 长计划、说明书或报告在用户点击入口后再加载为独立静态页面。
- 发布 manifest 记录所有受管文件、大小和 SHA-256；上传后逐文件线上比对。

这样首次打开更快，缓存也能独立复用；同时仍可用 manifest 防止漏传资源或线上版本不一致。

## 常见问题：直接这样告诉 Agent

| 现象 | 直接说法 |
| --- | --- |
| 404 | “线上出现 404，请检查隔离发布副本、素材和链接路径；不要在线上手工补文件。” |
| 图片或样式丢失 | “线上素材丢失，请检查相对路径和发布副本。” |
| 页面被拦截 | “浏览器拦截了页面，请检查是否跳转到 `data:` 新标签；改为站内正常阅读。” |
| 内嵌页面跳回首页 | “页内导航跳回首页，请让锚点留在阅读器内部，并做回归测试。” |
| 更新后仍是旧页面 | “文件已部署但不要报告上线成功，请核对线上版本哈希。” |
| 手机打不开 | “请记录运营商、时间和错误页截图；不要自行更换域名或购买资源。” |

## 最终验收

1. 用电脑打开网址，检查首页、导航、图片、表格和主要按钮。
2. 用手机关闭 Wi-Fi 后，使用移动网络打开同一网址。
3. 确认页面没有横向滚动条，弹窗、长表格和导航可用。
4. 核对 Agent 的四级状态全部成功，网址没有变化。

## 回退

网站异常时，不要删除线上目录或手工拖文件覆盖。对 Agent 说：

> 线上版本异常。请使用最近一版受管发布产物回退；先告诉我将要重部署的版本、哈希和零成本检查，完成后重新验证线上网址。

Agent 应报告将要使用的历史版本、重新部署结果和新的线上验证结果。
