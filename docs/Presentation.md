# 公开工作台的背景与界面

v3.5.0 将公开模板的背景与 UI 对齐维护者当前个人 HTML 工作台。同步范围是视觉和页面组织；账号、真实训练、饮食档案、私人知识和部署配置不进入模板。

- 使用同一组静态背景、桌面视频和手机视频，以及相同取景与遮罩；减少动态效果时保留静态图。
- 采用同一套字体、字号层级、透明表面、边框、间距和折叠布局。
- 桌面使用左侧导航，手机使用底部导航与本页目录；今日、训练、饮食、进展和知识库保持一致的位置关系，趋势、设置与指南保留次级入口。
- 训练日历、周期进度和复盘资料使用共享设计。公开版继续使用自己的离线存储、备份、纠错和可选云连接，不复制维护者的业务配置。

背景的原始字节哈希和批准范围记录在 [presentation-provenance.json](../skills/lzheng-fitness-workbench-builder/assets/presentation-provenance.json)。该文件不包含维护者的磁盘路径。模板的数据块保持为空，首次使用由 Agent 写入使用者自己的资料；“待建档”只用于空白初始化，真实计划仍按既有主动刷新流程立即展示。

已有工作台可让 Agent 按 [升级说明](UPGRADE.md) 执行受保护界面升级。保留原文件路径、实例身份、知识正文、记录与自定义壁纸；只有官方旧版会自动迁移，未知自定义仍需保留并审阅差异。安装新版 Skill 不代表旧 HTML 已经换上新界面。

此更新不改变小程序视觉基准，也不部署维护者个人网站或小程序。
