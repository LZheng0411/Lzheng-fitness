# Lzheng 力量训练周期设计规则

## 核心模型

把可见表现理解为：

```text
当天表现 ≈ 已获得的长期能力 - 尚未消退的短期疲劳 + 当天波动
```

训练同时制造适应和疲劳。积累期主要建设能力，强度期提高专项性，实现/减量期降低疲劳并让能力表现出来。这个式子是决策模型，不是精确生理公式。

## 六个控制变量

| 变量 | 作用 | 常见错误 |
| --- | --- | --- |
| 训练量 | 提供足够有效刺激 | 只用吨位判断，不看RPE和动作质量 |
| 负荷强度 | 提高大重量专项性 | 重量提高后仍保留全部组次 |
| 努力程度 | 控制单组刺激和疲劳 | 把每组力竭当作有效 |
| 频率 | 分配训练量、增加技术暴露 | 把频率本身当成进步来源 |
| 专项性 | 让训练接近目标表现 | 全周期都只做变式或轻重量 |
| 疲劳成本 | 决定可恢复训练量 | 卧推、深蹲、硬拉使用同一组数 |

## 阶段用途

| 阶段 | 主要任务 | 常见次数 | 常见RPE | 训练量趋势 |
| --- | --- | --- | --- | --- |
| 积累 | 肌肉、技术、工作容量 | 5—8 | 7—8 | 最高 |
| 强度 | 把基础转化为大重量能力 | 3—6 | 7.5—8.5 | 中等 |
| 实现 | 适应目标负荷、减少非专项疲劳 | 1—4 | 8—9 | 较低 |
| 减量 | 消除疲劳、保留动作感觉 | 1—5 | 6—8 | 明显降低 |
| 验证 | 检查周期结果 | 按目标测试 | 最高9—9.5 | 极低 |

百分比只能作为起点。优先用近期标准动作顶组和 RPE 校准实际重量。

## 多组 RPE 书写与判定

- RPE 是逐组记录的努力程度，不是固定重量、固定次数的多组动作必须维持的常数。
- 处方中的多组正式工作应写为“首组 RPE→末组 RPE”，例如 `4×6 @6→7`；前者是首组起点，后者是完成上限。
- 单组顶组、测试尝试可以使用单一 RPE 或 RPE 区间。顶组后的回退组、容量组和辅助组即使使用同一重量，也按箭头格式书写。
- 末组超出上限、掉次数或动作变形时，当天不追补；下一次按回退组进阶决策保持、降重或减组。
- 历史记录写逐组实际 RPE，或明确写“末组 RPE”；不要把历史摘要中的单一 RPE误读为未来多组处方。

## 顶组、回退组和未完成分支

### 顶组

- 用于校准当天状态和接触较高负荷。
- 通常为 1 组，目标 RPE 多为 8 左右。
- 不是每周最大测试，也不是默认 AMRAP。

### 回退组

- 是计划内的正式训练量。
- 通常比顶组降低约 5%—12%，具体幅度随动作和阶段变化。
- 顶组明显超出目标 RPE 后，要同步降低重量、次数或组数。

### 未完成/退行分支

- 只在原目标未完成时启用，替代原安排。
- 不把失败次数补回来，不因失败追加惩罚组。
- 先判断是一次状态波动、选重错误、技术问题还是累计疲劳。

## 动作差异

| 动作 | 常见特点 | 周期处理起点 |
| --- | --- | --- |
| 卧推 | 全身疲劳相对低，技术频率收益高 | 可安排较多回退组和每周两次以上暴露 |
| 深蹲 | 局部与全身疲劳都较高 | 强度日与容量/技术日分工，回退量中等 |
| 硬拉 | 绝对重量和后链疲劳高 | 顶组次数更低、回退组更少；低频时按暴露次数推进 |
| 负重引体 | 体重是总负荷的一部分 | 记录体重，用总系统负荷比较表现 |
| 推举 | 小幅加重相对更大 | 优先使用微加重、次数推进和较慢周期 |

对训练者个人而言，实际疲劳排序可能不同；用训练记录修正起点。

## 频率原则

- 频率首先用于分散训练量和练习技术，不是越高越好。
- 一周两次可设“强度日 + 容量/技术日”。
- 重主项两周一次时，用“第 1、2、3 次有效暴露”规划，不强行每周加重。
- 重硬拉两周一次可以成立，但间隔周通常应保留低疲劳髋伸或硬拉变式，除非恢复或疼痛限制不允许。

## 周期长度选择

### 8周

适合高频动作、单一目标或仍接近线性推进者。常用结构：3周积累 + 1周减量 + 3周强度 + 1周验证/过渡。

### 10周

适合一般力量发展。常用结构：3周积累 + 1周减量 + 3周强度 + 2周实现 + 1周验证。

### 12周

适合低频动作、恢复较慢或需要完整阶段者。常用结构不是硬性模板，可以是 3+1、3+1、2+1+1，也可以按 6 次主项暴露分配。

## 进阶决策

### 顶组

| 实际结果 | 下一次处理 |
| --- | --- |
| 达到次数上限且不超过目标RPE | 增加约1%—3%或最小杠铃片，回到次数区间下部 |
| 在次数范围内且RPE合适 | 保持重量，优先增加1次 |
| 完成目标但高于目标RPE约1级 | 保持重量和次数，目标是降低RPE |
| 未到次数下限已到RPE9 | 停止顶组，降低当日回退组；下一次重复或降重 |
| 动作标准破坏 | 不把该次算作达标，立即转入技术/降重分支 |

### 回退组

| 实际结果 | 下一次处理 |
| --- | --- |
| 全部完成且最后一组仍低于目标RPE | 先增加一次或小幅加重，二选一 |
| 全部完成但末组达到上限RPE | 保持 |
| 最后一组少1次 | 不补做；下次重复，必要时减少一组 |
| 多组未完成或RPE持续漂移 | 降低2.5%—7.5%或减少1—2组 |

### 连续异常

一次状态差视为波动。连续两次同动作出现以下信号，才优先判断为计划问题：

- 同重量次数下降；
- 相同组次 RPE 上升约1级；
- 技术或速度持续恶化；
- 酸痛、睡眠或日常疲劳持续影响训练。

处理顺序：先减辅助和回退组，再调整主项重量，最后考虑提前减量或更换阶段。

## 估算力量

有必要时可用 Epley 公式作为粗略比较：

```text
e1RM ≈ 重量 × (1 + 估计极限次数 / 30)
估计极限次数 ≈ 已完成次数 + RIR
```

负重引体等自重负重动作：

```text
总系统负荷 = 当天体重 + 附加重量
附加重量e1RM ≈ 总系统负荷e1RM - 当天体重
```

公式只用于同一动作标准下的趋势比较，不替代 RPE、动作质量和真实表现。

## 减量规则

- 普通减量优先减少约30%—60%的正式组数。
- 保留少量主项和中等强度，避免完全失去动作感觉。
- 不把减量周换成大量新动作、力竭辅助或高强度有氧。
- 如果用户没有明显疲劳且表现仍在提高，可以延后减量；如果连续异常，可以提前。

## 安全边界

- 锐痛、麻木、放射痛或持续加重的关节痛：停止该动作高强度推进。
- 卧推大重量需要保护杠或可靠保护者；深蹲使用安全杆；硬拉不追补失败次数。
- 不用疼痛、严重动作变形或频繁失败证明努力程度。
