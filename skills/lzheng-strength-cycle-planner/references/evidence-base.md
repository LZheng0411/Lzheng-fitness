# Lzheng Fitness 证据基础（Skill 内置版）

## 决策优先级

```text
当前官方安全标准
→ 用户本次明确确认和经授权、可核验的当前记录
→ 多来源一致的稳定训练原则
→ 当前计划与历史记录
→ 单一模板或估算
```

## 稳定原则

- 从用户当前能力和可执行条件开始，训练量、强度、频率与目标相匹配。
- 固定器械、自由重量、弹力带和自重都可有效；器械形式按目标、稳定要求、偏好和疲劳成本选择，不表示训练等级。
- 训练一致性和渐进比无必要的复杂技术更重要。
- 公共健康目标应逐步接近；低活动用户先从可完成的小量开始。
- 锐痛、麻木、放射痛、晕厥、胸部异常不适、异常气短、明显功能受限或持续加重症状不进入普通高强度处方。
- Skill 不作医疗诊断，也不替代合格专业人员的个体评估。
