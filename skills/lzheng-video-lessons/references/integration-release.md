# 接入与发布验收

1. validate → build 到新目录 → 本地试看 → integrate 预检/apply（备份）。用户已经授权的步骤直接执行。
2. 手机 390px 与桌面：目录展开不移动正文、单列选段、键盘 Escape、编号讲解、来源链接；关闭课程暂停并卸载视频、回到原页面。不得重置训练输入。
3. 真实媒体检查 readyState/videoWidth、实际画面、起止点、重播/循环、跳转；源链接模式明确无法保证第三方按时间播放。
4. 计划刷新前后知识注册保持不变。需要构建工作台副本时用既有 builder，当前版本的 Prepare/Check 支持 knowledge-lessons-data 依赖。public-anonymized 默认丢弃用户知识，不能假定课程已发布。
5. 发布到用户已有目标，使用配置或工具返回地址，不内置维护者云环境。若当前发布器不识别课程依赖，先做适配并测 manifest，不能只上传首页。授权媒体以 media_rights_basis 记录，工具不会验证授权真实性。
6. 发布后 `python scripts/lesson.py verify-online --lesson <目录> --base-url <该课程线上目录HTTPS>` 对全部受管文件做HTTP和SHA256检查。这个命令只能证明课程文件一致，不能代替工作台依赖/远端多余文件检查、真实浏览器与访问权限验收。
7. 保存发布器回执和线上证据；明确部分完成状态。失败保留新目录与旧入口，不假报上线。

开源提交仅包含 Skill、代码、模板和虚构夹具。排除 runtime、媒体、字幕原文、浏览器状态、个人笔记、账号配置、主机路径与密钥。独立安装依赖 Python3 标准库；来源获取可选 Playwright/Chrome/转写工具；浏览器测试依赖 Playwright。没有其他 Skill 时仍可 validate/build；集成/发布使用目标已有工具链，不承诺所有 Agent 或托管平台自动兼容。

兼容旧个人页面：保留首个旧课程及训练联动，新课程使用通用目录追加；不会重排旧首项。若更新旧首项的标题/署名/章节数等而旧UI仍写死文案，预检会要求先迁移该UI，避免悄悄显示旧标题。
