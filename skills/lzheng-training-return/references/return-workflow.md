# 七天训练接回工作流

## 1. 总原则

恢复期的目的不是证明能力仍在，而是恢复可持续训练。优先级是：

```text
安全
→ 出勤与动作质量
→ 训练后恢复
→ 恢复计划容量
→ 重新推进表现
```

## 2. 压力回退逻辑

不使用单一百分比机械降载。综合考虑中断时长、原因、症状和恢复、动作熟悉度、当前器械、停训前训练压力以及是否反复中断。

保守顺序：先降低接近力竭程度和总组数，再在需要时降低负重或动作难度。任何百分比都只是起始建议，必须由热身表现、RPE/RIR 和症状反应修正。

## 3. 三档任务

### 正常版

- 使用原计划中稳定、熟悉的主要动作；
- 降低训练压力，不做极限测试；
- 保留必要动作模式，删除非必要容量；
- 训练结束应留下可恢复余量。

### 降级版

- 主项使用更保守的重量、RPE 或动作变式；
- 每个主要动作少做 1 组，或删除 1—2 个孤立动作；
- 取消额外有氧和高疲劳收尾；
- 以动作质量和第二天反应决定是否升级。

### 最低版

- 10—20 分钟；
- 只保留启动、一个主要动作模式和一个低疲劳辅助或稳定动作；
- 不追重量、不力竭、不制造补课压力；
- 完成后直接安排下一次接回时间。

三档必须来自同一计划主线，不得互相变成三套无关计划。

## 4. 七天结构

### 第 0—2 天

- 完成安全筛查和状态快照；
- 在 48 小时内完成最低版或第一次接回训练；
- 记录训练中症状、主观用力和第二天反应。

### 第 3—5 天

- 若无异常且恢复可接受，完成第二次训练；
- 可以从最低版升级为降级版，或从降级版升级为正常版；
- 仍不做极限测试和补课。

### 第 6—7 天

- 复盘出勤、症状、动作质量、RPE偏差和恢复；
- 决定下一周：恢复原计划、继续过渡、重新设计计划或暂停并转介。

7 天是第一次完整复盘窗口，不是硬性毕业日期。

## 5. 决策标准

### 升级

- 训练中无异常症状；
- 目标动作能稳定重复；
- 实际 RPE 未明显高于预期；
- 24—48 小时恢复在可接受范围；
- 用户愿意继续且时间条件允许。

### 维持

- 能完成但余量较少；
- 动作质量尚可但波动；
- 睡眠、压力或酸痛仍影响恢复。

### 降级

- RPE明显高于预期；
- 动作稳定性下降；
- 恢复明显变差；
- 用户只能完成部分计划。

### 暂停并评估

- 疼痛明显或加重；
- 麻木、功能受限、胸痛、晕厥或异常气短；
- 生病症状反复或全身状态恶化；
- 专业人员给出的限制尚未满足。

## 6. 反复中断

4 周内反复中断时，不把问题只归因于意志力。检查计划频率、短版缺失、场地通勤、器械摩擦、恢复能力、生活压力、目标优先级以及动作的技术或心理成本。

如结构性条件已变化，返回 `lzheng-fitness-plan` 重建对应部分。
