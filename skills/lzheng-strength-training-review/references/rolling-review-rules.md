# 无周期滚动复盘规则

涉及逐组事实、RPE、渐进或失败反馈时，先按[训练数据判断与渐进协议](training-progression-protocol.md)判断；本文件中的通用数值为候选示例，不能覆盖本人目标、真实反馈和明确约束。

## 可比记录

默认读取最近 2—4 次训练。只有同时满足以下条件才作为同一推进序列：

- 同一动作及动作标准；
- 同一器械和重量口径；
- 正式组而非热身、测试或失败追补；
- RPE 与 RIR 能统一换算，或至少有动作质量和完成次数；
- 负重引体等自重负重动作有当天体重，缺失时明确降低比较可信度。

动作替换、器械改变、握距/幅度明显改变或疼痛导致的降级训练，不能直接与原动作合并推进。

## 用户渐进方式检查

先识别用户是否已有明确方法，例如双重渐进、固定次数加重、顶组加回退、次数区间或 RPE 自调节。

以下情况可继续沿用：

- 按目标解释重量、组次、休息和质量的联合变化；
- 多数工作组保持在目标 RPE 内；
- 动作标准稳定；
- 最小加重单位与动作相匹配；
- 最近 2—4 次没有连续退步或恢复恶化。

以下情况必须点明并纠正：

- 无依据同时增加多项任务，且没有恢复预算或超标分支；
- 依靠频繁力竭或失败完成推进；
- 连续两次同重量掉次数或 RPE 上升约 1 级；
- 动作标准、器械或活动幅度变化后仍直接比较成绩；
- 辅助动作持续挤占下一次主项质量；
- 用户的最小加重幅度相对当前能力过大。

## 默认滚动决策

| 最近表现 | 下一次处理 |
| --- | --- |
| 达到次数上限，末组未超过目标 RPE | 增加一个最小重量单位，次数回到区间下部 |
| 次数在目标区间内且 RPE 合适 | 按目标与职责选择：容量/肌群辅助通常保重量，仅给有余力的组加次数；力量顶组可评估合适增量，具体遵守共同协议，不强制每组都加 |
| 全部完成，末组达到 RPE 上限 | 检查前组余力，可保持或局部推进；不得忽略累计影响 |
| 单次少做或 RPE 偏高 | 不追补；先核对原因，暂时异常解除可重试，正常执行仍失控则预先调整 |
| 可比条件下反复掉次数或超标 | 复查恢复和整周任务，调整组次或休息；降重须说明原因和返回推进条件，不固定套百分比 |
| 首组就超过目标 RPE 或动作失控 | 当天降低重量或次数，不执行原定推进 |

允许重量、次数、组数和休息联合调整，明确目的、取舍与反馈分支。小幅调整可直接成为下一次处方；需要改变频率、训练日、动作体系、测试目标或规划三次以上暴露时，改为待确认结构调整。

## 数据不足时的基准训练

- 只有一条可靠记录：可建立可比基准，也可在明确有余力且质量合格时提出小幅试探；不强制先重复。超标时按原因调整重量、组次或休息，降重须解释。
- 卧推、深蹲、推举：逐级热身，选择能完成 `3×5 @6→7` 的重量。
- 硬拉：选择 `1×5 @6—7`，再降低约 8%—10% 完成 `2×5 @6→7`。
- 负重引体：记录当天体重，以自重或最小附加重量完成 `3×5 @6→7`。
- 辅助动作：选择能完成 `2×8—12 @6→7` 的重量。

完全没有可靠重量时，只写热身选重步骤和目标 RPE，不给精确公斤数。

## 无周期安全边界

- 锐痛、麻木、放射痛或持续加重的关节痛：停止该动作高强度推进。
- 连续两次表现下降时先检查睡眠、疼痛、动作标准、休息时间和辅助量，再决定减重。
- 不因一次 RPE 偏低自动生成多周周期或测试目标。
- 积累 3—4 次稳定可比暴露后，可以建议建立周期；未经用户确认不得自动创建。
