# 视觉契约

工作台唯一视图资产为 `../assets/workbench-template.html`，模板版本为 `lzheng-fitness-workbench-v2`。AI 只生成或刷新 `workbench-data`，不得改写模板导航、组件和视觉。跨页面职责见 `../../lzheng-training-system/references/html-template-contract.md`。

## 固定语言

- 黑、白、灰为主，不依赖彩色表达状态。
- 全局背景、Hero 和桌面侧栏共享同一组图片资产，但各自使用不同遮罩与取景。
- Hero 是唯一大面积深色信息区；其他卡片使用半透明暖白材质，让背景可见但不干扰阅读。
- 桌面侧栏为深色玻璃，手机端改为底部导航。
- 必须使用 Skill 内置的饿狼图片资产；正式 HTML 和发布副本均使用本地相对路径，不使用外链。

## 信息层级

1. 今天练什么或恢复什么；
2. 精确重量、组次、RPE/RIR 与完成标准；
3. 周期位置和下一验证点；
4. 负荷趋势与近期复盘；
5. 数据同步、规则和使用说明。

当动作处于重量校准状态时，优先显示“从轻重量试组 → 小幅增加 → 记录重量、次数、余力和动作质量”的操作引导；不能把待校准误写成正式处方。

不要把所有信息做成同一种纯文本白卡。计划、训练日、趋势、复盘和同步状态使用不同组件结构。

## 图表

- 已执行：深色实线和实心点；
- 后续计划：灰色虚线和空心点；
- 实际与计划重合：只保留实线；
- 数值标签必须保持字体比例，禁止横向压扁；
- 绘图区可透视背景，但需要网格、边界和对比度保证可读。

## 响应式

- 375px：单列、无横向滚动、底部导航可触达；
- 900px 以下：趋势和复盘单列；
- 1440px：内容区约 1180px，趋势双列，侧栏不挤压正文；
- 动态长文本必须换行，重量和组次不得被截断。
