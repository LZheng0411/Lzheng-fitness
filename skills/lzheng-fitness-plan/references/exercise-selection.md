# 动作与器械适配规则

## 动作记录字段

为候选动作建立：

`name`、`pattern`、`muscles`、`modality`、`equipment`、`skill_demand`、`stability_demand`、`local_fatigue`、`systemic_fatigue`、`prerequisites`、`caution_flags`、`goals`、`regressions`、`progressions`、`alternatives`、`pass_criteria`。

评分只用于比较同一用户的候选动作，不假装是医学风险量表。

## 选择顺序

1. 删除器械不存在、出现明确异常症状或不满足基本前提的动作；
2. 匹配计划所需动作模式和目标肌群；
3. 选择用户当前能稳定重复的最低必要技术难度；
4. 比较目标刺激、局部疲劳、全身疲劳、时间和学习成本；
5. 保留没有问题且持续有效的熟悉动作；
6. 为每个核心动作提供同目的替代和升级标准。

固定器械通常更稳定、容易接近目标肌群和调节负荷，但不是自动更安全；自由重量通常需要更多协调并更容易进行专项训练，但不是自动更高级。依据用户与目标选择。

## 分层起点

### P0

优先高稳定、易学习、易调重动作。每次 4—6 个动作，最多放入一个受控自由重量学习动作。

| 模式 | 优先候选 | 条件式候选 |
| --- | --- | --- |
| 膝主导 | 坐站、腿举、哈克深蹲、箱式杯式深蹲 | 轻杠铃深蹲学习 |
| 髋主导 | 臀推、腿弯举、绳索拉臀、垫高壶铃硬拉 | 轻哑铃 RDL |
| 水平推 | 器械推胸、上斜俯卧撑、稳定哑铃推 | 空杆卧推学习 |
| 水平拉 | 坐姿划船、胸托划船 | 轻哑铃单臂划船 |
| 垂直推 | 器械肩推、轻哑铃推举 | 空杆推举学习 |
| 垂直拉 | 高位下拉、辅助引体 | 标准引体学习 |
| 核心 | 死虫、Pallof、低负荷农夫走 | 更高难度抗伸展 |

### L1

使用器械与自由重量混合。主线动作保持 4—6 周；用双进阶；技术未稳定的自由重量仍按学习动作处理。

### L2

按目标决定专项性。力量目标可以用杠铃主项，增肌目标用器械和支撑动作控制疲劳；不要为了分化名称堆动作。

### L3

比赛或成绩目标保留专项动作，固定器械可以作为低技术、低系统疲劳的容量动作。高级技巧只有在解决明确平台或约束时使用。

## 传统硬拉准入

传统硬拉不是通用计划必选项。进入地面传统硬拉前确认：

- 无痛髋铰链；
- 能在轻负荷下保持可重复的躯干和杠铃路径；
- 有合适杠铃片、地面空间和教学条件；
- 用户有明确的硬拉力量、技术或专项目标；
- 当前全周疲劳预算允许。

学习顺序：

```text
髋铰链练习 → 垫高壶铃硬拉 → 高把陷阱杠或轻 RDL → 地面传统硬拉
```

一般健康、减脂或增肌目标可用臀推、腿弯举、RDL、背伸或绳索拉臀训练后链。恐惧明显、技术反复失控、场地不合适或腰背异常症状未澄清时不安排地面传统硬拉。

## 替代规则

替代必须保持至少一项主要职责一致：动作模式、目标肌群、专项性或疲劳预算。不要只因器械排队就随机换成无关动作。

为每个主动作写：

- 首选动作和选择原因；
- 同场地替代；
- 更低技术/更高稳定回退；
- 进入更高难度版本的可观察标准；
- 出现何种信号应停止而非继续回退。
