# HTML 输出规范

## 内容顺序

页面采用“训练 App 快速入口 + 完整报告”：

1. 页头：计划名、状态快照时间、整体阶段、阶段目标；
2. 下一次训练：训练日、预计时长、标准/30/20/10 分钟入口；
3. 本周日历；
4. 各训练日动作卡和替代动作；
5. 动作模式与肌群覆盖；
6. 渐进、状态差和短期漏练规则；
7. 用户主动启用后的单项周期引用；
8. 复盘节点；
9. 本次实际使用的知识来源；
10. 安全边界、假设和未知项。

不要在第一屏堆理论、长表和来源列表。未启用周期时不显示空周期区。

## 视觉和交互

- 白底、浅灰信息区、深绿强调色；警告仅使用低饱和橙色；
- 禁止渐变、多色仪表盘和厚重卡片；
- 默认读取本 Skill 的 `assets/header-lineart.png` 并转 Base64；找不到时使用纯文字页头；
- 训练日用可扫描卡片；标准/30/20/10 分钟用按钮切换；
- 关闭 JavaScript 时仍至少展示标准版；打印时展开所有版本；
- 手机端单列、隐藏装饰图；长表允许横向滚动；390px 视口下页面的 `scrollWidth` 不得大于 `clientWidth`，只有导航、周计划卡片或长表等明确容器可以内部横向滚动；
- 一级导航固定为 `概览｜本周｜训练日｜进阶｜规则`，必须使用固定定位并在滚动到页面任意位置时保持可用；不得把分层、覆盖、来源或假设加入一级导航。
- 提供 `scroll-margin-top`，固定导航不能挡标题。
- 每个动作必须显示已核验工作重量与下一次规则，或显示逐步校准引导；禁止只留下“自行选择重量”。

## 技术边界

- 单个 UTF-8 HTML；
- CSS 和少量交互脚本全部内嵌；
- 不使用 CDN、网络字体、外部脚本、iframe 或远程图片；
- 外部官方来源可以作为普通超链接，但页面显示不依赖网络；
- 所有用户文本先 HTML 转义；
- 页面写入 `data-plan-id` 和 `data-snapshot-id` 便于审计；
- 生成器拒绝覆盖已有文件。

## 运行

```powershell
python scripts/validate_plan.py <plan.json>
python scripts/render_fitness_plan.py <plan.json> <output.html>
python scripts/audit_html_plan.py <output.html> --plan <plan.json>
```

交付前在宽屏、窄屏和打印样式检查：标题、按钮、动作卡、长文本、中文换行和来源列表均可读。
