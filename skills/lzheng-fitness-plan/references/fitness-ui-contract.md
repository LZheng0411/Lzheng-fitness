# 计划页面视觉契约

计划页是执行界面，不是由 AI 临时设计的报告。AI 只生成 `plan_contract`，唯一渲染器负责 HTML。

## 固定结构

1. 保留大海报、计划名称、阶段和状态快照；人物线稿可作为计划页视觉资产。
2. 一级导航固定为：`概览｜本周｜训练日｜进阶｜规则`，必须固定在视口顶部且始终可用。
3. 训练日优先展示动作、工作重量或校准引导、组次、RPE/RIR、休息和短版切换。
4. 分层、覆盖、来源和假设属于完整报告，只能在次级内容中出现，不得增加一级导航。

## 设计边界

- 计划页固定使用白底、浅灰信息区、深色文字和深绿状态强调；禁止每次生成时自行换主题。
- 健身工作台使用独立的黑白灰饿狼视觉；饿狼图片不是计划页的强制素材。
- 只能修改模板、渲染器和视觉契约；普通计划生成不得手写新 CSS 或组件。
- 桌面与手机都必须保持固定导航、无横向页面溢出和可读的训练日动作卡。
