# P0—L3 训练者分层

训练等级描述“当前需要多复杂的计划才能继续可靠进步”，不是身份、天赋或价值排序。训练年限和绝对力量只作证据之一。

## 判定维度

同时检查：

- 最近 4—8 周执行稳定性；
- 基础动作是否可重复；
- 能否理解和记录组数、次数、RPE/RIR；
- 可靠进步出现的时间尺度；
- 恢复是否可预测；
- 是否需要计划性变动才能继续进步；
- 目标是否已经专项化。

## 整体分层

| 层级 | 识别信号 | 计划复杂度 | 默认周期 |
| --- | --- | --- | --- |
| P0 启动/回归 | 最近训练不稳定、动作需学习、无法稳定选重或停训回归 | 少动作、低技术、保守起量、先记录 | 4 周 |
| L1 新手 | 可以逐次或隔次增加重量/次数，动作与记录初步稳定 | 全身 A/B、简单线性或双进阶 | 4—6 周 |
| L2 中级 | 逐次加重失效，进步按周发生，能识别恢复与RPE | 主次训练日、按周渐进、必要时减量 | 6—8 周 |
| L3 进阶 | 进步按月或阶段发生，目标专项化，记录与恢复判断可靠 | 专项化、疲劳预算、按需周期 | 6—12 周 |

如果证据跨层，使用较保守的整体层级并说明“早期/后期”。不要因为训练了几年自动升级。

## 单动作分层

对计划中高影响动作分别记录：

- `movement_stage`：P0/L1/L2/L3；
- `technique_status`：未学习/学习中/稳定/专项；
- `progress_timescale`：逐次/隔次/按周/按月；
- `evidence`：近期记录、视频、用户描述或待验证；
- `prescription_role`：学习、基础、主项、容量、辅助。

整体等级不能覆盖单动作差异。例如整体 L2 但硬拉未学习，则硬拉仍按 P0 处理。

## 通过标准

### P0 → L1

- 连续 2—4 周完成现实频率；
- 基础动作无明显不适，能按标准重复；
- 能理解组数、次数、休息和至少粗略 RIR；
- 能保存训练记录；
- 不依赖每组力竭判断努力。

### L1 → L2

- 多数主动作已无法长期逐次加重；
- 能用周趋势而非单日情绪判断表现；
- 能稳定执行 4—8 周计划；
- 能识别动作变形、恢复异常和 RPE 超标。

### L2 → L3

- 进步确实按月或阶段发生；
- 目标需要更高专项性；
- 至少一个完整周期的记录可靠；
- 增加复杂度能够解决明确问题，而非追求高级感。

ACSM 2026 对普通健康成年人强调稳定与个体化，复杂周期、高级技巧和力竭并非自动必需。因此 L3 也应使用“最低有效复杂度”。
