# 单文件 HTML 模板总契约

本项目只允许三类单文件 HTML。所有页面都必须由结构化数据和仓库内固定模板生成；AI 不得手写整页 HTML、增加一级导航、改写设计令牌或临时创造组件。

| 页面 | 唯一模板 | 固定职责 | 禁止承担 |
| --- | --- | --- | --- |
| 完整健身计划 | `lzheng-fitness-plan/assets/fitness-plan-template.html` | 解释阶段目标、本周结构、按日简表处方、如何渐进、AI 复盘节点、动作模式与健美肌群折算组数 | 今天/下一次练什么、完成按钮、实时记录、安全筛查、漏练判断、来源与假设 |
| 力量周期规划 | `lzheng-strength-cycle-planner/assets/strength-cycle-template.html` | 展示单个或多个力量主项的 8—12 周周期、曲线、每次暴露和调整规则 | 代替完整计划、推算今日训练、显示完成状态 |
| 健身工作台 | `lzheng-fitness-workbench-builder/assets/workbench-template.html` | 展示今天或下一次训练、完成状态、周期位置、实时数据、趋势与复盘 | 重新定义长期计划、生成新的训练处方 |

## 不可变规则

1. 模板的 `<html>` 必须带唯一 `data-ui-template` 版本。
2. 一级导航、一级区块顺序、颜色、字体、间距、响应式断点和组件 class 属于模板，不属于计划数据。
3. JSON 是唯一可变主源。文本、动作、重量、组次、RPE/RIR、日期、图表数据和来源只能从 JSON 注入。
4. 所有注入文本必须转义；不允许 JSON 提供 HTML、CSS、脚本、class 名或导航名称。
5. 单文件计划与周期页不得依赖 CDN、网络字体、远程脚本或远程图片。工作台的视频、海报和图片使用 Skill 内置相对资产并随发布目录复制。
6. 模板资产只由维护任务修改。普通计划生成、复盘、接回和迁移任务只能调用渲染器或数据构建器。
7. 渲染后不得残留 `__TOKEN__` 占位符。校验未通过时拒绝交付。

## 固定导航

- 完整计划：`概览｜本周｜训练日｜进阶｜覆盖`。
- 力量周期：`概览｜周结构｜训练日｜周期｜规则`。
- 工作台：`训练｜计划｜负荷｜复盘｜数据`；桌面侧栏、手机底栏。

## 评审与升级

模板视觉调整必须先修改模板资产，再升级 `data-ui-template` 版本并同步对应渲染器与校验器。不得直接修改某一份用户 HTML 后把它当成新规范。
