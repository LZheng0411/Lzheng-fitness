# 详细蒸馏报告契约

以下标题供 `distill_report.py` 识别。每节填写具体内容，不留模板占位。适合短片时可以简短，但关键方法和边界不能只写套话。

- `## 问题与来源`：用户要解决的问题；作品链接、上传者、讲者身份状态、来源包核验状态。
- `## 作者核心观点`：作者在片中实际提出的主张，不能写成通用事实。
- `## 完整方法`：步骤、数字、单位、公式、判断条件、例外及片中的例子；没有就明确说没有。
- `## 时间段证据`：至少一个与原转写时间范围相符的 `[00:00.000–00:00.000]` 定位，说明支持什么主张；画面证据须注明已回看。
- `## 适用前提与边界`：作者说出的前提与 Agent 另行分析的边界分开。
- `## 不确定与分歧`：转写、画面、身份、因果推断或与其他证据冲突的未决点；没有发现也说明核对范围。
- `## Agent 分析与应用`：对提问者有何价值、怎样小范围尝试、用什么反馈判断、什么条件尚不具备。个人处方或记录不在此处自动修改。

报告头部的 `source_packet_sha256` 和 `transcript_sha256` 是材料版本标记。来源包或转写改变时，重新核对报告，不能只替换哈希。验证脚本只检查结构、时间段范围和指纹一致，不判断内容真伪。
