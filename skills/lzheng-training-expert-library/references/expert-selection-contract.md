# Lzheng 专家选择协议

## 原则

先拆变量，再选最少必要专家。默认 1 位；只有第二个来源负责独立变量、会改变结论或需要解释真实冲突时才增加。不得投票，不因名气或展示效果增加人数。

## 变量路由

| 问题变量 | 主要模块 | 需要时追加 |
| --- | --- | --- |
| 营养、宏量、补给、补剂、依从性、维持 | Alan Aragon | 增肌刺激受限时追加 Brad；训练结构受限时追加 Eric |
| 肌肥大机制、增长测量、有氧并行 | Brad Schoenfeld | 一般不追加 |
| 增肌训练量、频率、力竭、活动范围、动作选择 | Brad Schoenfeld | Eric Helms 检查整体结构与恢复 |
| 一般计划结构、依从性、渐进、减载 | Eric Helms | 不因力量目标自动追加 Greg |
| 力量停滞、专项技能、变量实验、峰值、三项技术假设 | Greg Nuckols | Eric Helms 检查上游计划和恢复 |
| 目标含糊、反复中断、明显动作缺口、回到基础 | Dan John | 再按主变量选择 Eric、Greg、Brad 或 Alan |
| 已获专业允许活动后的功能进阶、返场和复发预防 | Brukner 与 Khan | 只有“最低可执行路径”是独立变量时追加 Dan John |

疼痛未评估、急性创伤、术后未获许可、孕期、疾病、胸部不适、晕厥、异常气短或进行性神经症状不进入专家讨论，先执行安全分流。

## 整合顺序

1. 主 Skill 读取当前事实：用户当次确认优先，其次是可验证的当前计划、执行基准与动态记录。
2. 每位专家只输出：来源限定判断、适用前提、必要保留、仍缺证据。
3. 主 Skill 说明共同结论、分歧来自版本/目标/证据还是适用条件。
4. 主 Skill 把当前事实放入条件分支，生成最终建议、记录指标和调整条件。

没有真实分歧时不制造辩论；证据不足时不生成假精确处方。
