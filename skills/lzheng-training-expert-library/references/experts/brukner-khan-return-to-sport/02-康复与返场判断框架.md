# 康复与返场判断框架

## 书本直接主线

本书把运动损伤置于“准确评估、保护受损组织、尽早且适当活动、分阶段恢复肌力/心肺/柔韧/本体感觉/功能与专项技能、再回归运动”的连续过程之中（第 4–5、11–15 章，印刷页 15–40、145–250）。回归不是由日历单独决定，而要看症状、组织/功能恢复、专项要求与风险沟通。

## Lzheng 的结构化应用

```text
危险信号、急性外伤、明显功能丧失或医学症状？
├─ 是：暂停普通训练；按医疗/急救流程转介，不使用本模块给诊断或处方
└─ 否：是否已有合格专业人员评估并允许活动？
   ├─ 否：只收集症状与训练事实，建议评估；不猜伤病名
   └─ 是：明确当前阶段与可做/不可做动作
      → 建立最低可承受活动与症状/次日反应基线
      → 先恢复基本活动与局部容量，再加入力量、平衡/控制、功能模式和专项暴露
      → 每次只改变少量变量；记录即时、24 小时和下次训练反应
      → 满足功能、专项暴露、信心与无异常反应条件后，逐级回归训练/运动
      → 保留负荷、恢复、技术与沟通的二级预防措施
```

## 信息门槛

至少确认：何时发生及机制、症状部位/性质/变化、能否负重和完成日常活动、麻木/无力/发热/胸痛/晕厥/异常气短等风险、既往同类问题、已做检查与医疗建议、目前可做活动、训练目标与专项需求、即时与次日反应。任一核心安全信息未知时，只给暂停或保守记录下一步。

## 进阶与回退条件

| 可考虑进阶 | 维持或回退 | 必须转介/暂停普通训练 |
| --- | --- | --- |
| 当前阶段任务可控完成；症状无进行性恶化；次日不出现超出基线的反应；功能接近下一阶段要求 | 训练中症状明显改变、次日反应恶化、代偿增加、恢复跟不上或记录不完整 | 急性严重创伤、不能负重/明显功能缺失、进行性神经症状、系统性症状、胸痛/晕厥/异常气短，或任何与既有专业意见冲突的情况 |

这里的“可考虑”不是医疗放行。回归竞技、碰撞运动、术后或有明确诊断的情形，必须服从负责临床团队的限制与测试标准。
