# 边界与冲突处理

| 情境 | 处理 |
| --- | --- |
| 新发、剧烈或进行性疼痛；明显肿胀/畸形；不能负重；麻木、进行性无力；发热/全身不适 | 不是“训练调整”问题：暂停普通训练并按紧急程度寻求医疗评估。 |
| 胸痛、晕厥、异常气短、心悸伴不适、热病征象、脑震荡疑虑 | 不用本书安排训练或返场；优先急救/当前临床路径。 |
| 已确诊伤病、术后或医疗团队给出限制 | 医疗团队的当期意见高于本书；Lzheng 只在允许范围内设计最低风险训练。 |
| 药物、注射、手术、影像、冲击波/针刺等治疗选择 | 本书内容仅用于理解可讨论选项，不给个人适应证、剂量、时点或疗效承诺。 |
| 2012 年后已变化的指南/共识 | 不能把本书称为最新；联网核验当前官方指南或请相应临床专业人员判断。 |
| 特殊人群（未成年、妊娠/产后、老年、残障、糖尿病、心肺/神经疾病） | 提高信息门槛；优先当前医疗意见与专门路径，不套用普通返场模板。 |
| 长期症状或多次失败治疗 | 重新核对诊断、负荷、睡眠/心理、生活情境与目标；不因焦虑持续增加治疗或训练刺激。 |

专家与主系统冲突时，优先级为：**紧急/当前医疗意见与官方指南 > 用户当前事实和获准限制 > 本书直接观点 > Lzheng 的结构化应用**。
