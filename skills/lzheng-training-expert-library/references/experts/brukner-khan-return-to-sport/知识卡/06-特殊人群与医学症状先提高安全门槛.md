# 特殊人群与医学症状先提高安全门槛

**解决的问题：**遇到脑震荡、胸痛、晕厥、异常气短、热病、感染或特殊人群，能否继续执行训练接回？

**核心命题：**这些问题首先是医学安全与专业协作问题，不是通过降低组数就能解决的训练问题。

**推理链：**本书专设脑震荡、特殊参与者、医学紧急情况、心肺/代谢/感染/环境问题与运动前评估章节（第 17、42–62 章，印刷页 272、888–1202）。这说明运动医学中的返场前提是适当评估和获准，而不是训练系统自行判断。

**可执行判断：**出现新发胸痛、晕厥、异常气短、进行性神经体征、热病/感染全身症状，或脑震荡、术后、妊娠/产后、未成年、慢病等情形时，停止普通模板；记录已知事实与现有医嘱，转向合格专业人员和当前路径。

**容易误用：**把“轻度活动有益”泛化成任何疾病/环境下都应训练，或拿旧教材取代当前医疗清除与指南。

**来源定位：**第 17、42–62 章，印刷页 272、888–1202。
