# 二级预防把训练负荷恢复与沟通接起来

**解决的问题：**恢复后怎样降低再次中断的风险？

**核心命题：**二级预防不是添加一个“纠正动作”，而是让训练负荷、恢复、技术/装备、专项暴露、沟通与记录重新形成反馈闭环。

**推理链：**本书将预防、恢复、康复后的二级预防及团队照护放在相互联系的位置（第 9–10、15、63–64 章，印刷页 115–144、246–250、1203–1220）。复发风险因此不能只由单个局部动作解释。

**可执行判断：**返场后继续记录周训练结构、关键动作暴露、症状和次日反应、睡眠/恢复、技术或器械变化；每次只调整少数变量，并让教练、医疗人员与训练者对限制/进阶条件有同一版本。

**容易误用：**把护具、热身或单次治疗当作“已预防复发”；隐瞒症状以赶回计划；恢复后直接回到停训前峰值训练量。

**来源定位：**第 9–10、15、63–64 章，印刷页 115–144、246–250、1203–1220。
