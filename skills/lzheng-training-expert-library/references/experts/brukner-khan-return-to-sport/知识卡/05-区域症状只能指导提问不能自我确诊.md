# 区域症状只能指导提问不能自我确诊

**解决的问题：**肩、腰、髋、腹股沟、膝、踝、跟腱等部位疼痛，训练系统能做什么？

**核心命题：**本书按区域组织内容是为了临床使用的高效评估，不是让训练者按部位名称自我贴标签；同一部位可有不同组织、牵涉痛、神经或非肌骨原因。

**推理链：**第 17–41 章覆盖从头颈到足的区域问题，第 7、11–12 章要求先排除伪装问题、收集机制和功能、只在会改变管理时使用检查（印刷页 54–60、145–163、272–887）。因此主系统只用部位来追问功能、机制与风险，而不能输出诊断名。

**可执行判断：**记录部位、发生机制、动作/负荷、是否能承重与完成日常活动、症状变化、伴随神经或系统症状、既往史和专业意见；据此决定转介或在许可内改成不诱发版本。

**容易误用：**以网络动作测试、疼点、影像名词或单一“纠正动作”代替评估；只因疼痛局限就排除转诊或系统性问题。

**来源定位：**第 7、11–12、17–41 章，印刷页 54–60、145–163、272–887。
