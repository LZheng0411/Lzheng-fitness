# 长期症状要重建问题而非不断加码治疗

**解决的问题：**长期反复不适、疲劳或多次“治疗无效”时下一步是什么？

**核心命题：**长期症状往往需要回到问题定义：诊断假设、训练与生活负荷、功能、心理与恢复、目标和已尝试措施，而不是把治疗数量或训练刺激继续叠加。

**推理链：**疼痛章节强调复杂系统与牵涉痛，第 41 章专门讨论长期症状，第 57 章讨论疲劳运动员（印刷页 41–52、878–887、1118–1131）。这支持“重新收集证据、找出可验证假设”的方式，而非承诺一个万能修复动作。

**可执行判断：**建立时间线：症状、训练变化、睡眠/压力、工作生活、既往检查及治疗反应；先删除明显恶化暴露，保留耐受活动，带着完整记录复评。没有稳定基线就不连续换方案。

**容易误用：**把症状持续自动归因为意志力、姿势或单一组织问题；把每一次短期好转当作原因为真。

**来源定位：**第 6、41、57 章，印刷页 41–52、878–887、1118–1131。
