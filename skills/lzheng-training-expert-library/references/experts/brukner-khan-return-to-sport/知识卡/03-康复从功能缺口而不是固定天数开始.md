# 康复从功能缺口而不是固定天数开始

**解决的问题：**获准恢复活动后，怎样从“休息几天”变成可执行康复？

**核心命题：**康复应围绕当前功能缺口与目标活动建立阶段，而不只按受伤后天数；基本活动、局部能力、心肺、活动范围、控制/本体感觉、功能模式和专项技能各有角色。

**推理链：**本书将肌肉状况、心肺、柔韧、控制、本体感觉、功能练习、专项技能和心理支持列为康复组成，并说明从初期到中期、进阶与回归的阶段性（第 14–15 章，印刷页 210–250）。这要求先清楚“现在不能完成什么”，再确定最低安全任务和下一道功能门槛。

**可执行判断：**针对已获准的动作，建立基线：日常功能、目标动作的简化版、症状与次日反应；只有当前任务稳定后再增加范围、负重、速度、复杂度或频率中的一项。

**容易误用：**把核心训练、本体感觉或拉伸当成每一种疼痛的固定处方；忽略心肺、专项技能或心理准备；把时间表当作返场证明。

**来源定位：**第 14、15 章，印刷页 210–250。
