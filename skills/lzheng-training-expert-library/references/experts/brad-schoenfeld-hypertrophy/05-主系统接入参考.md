# Lzheng 内部接入参考

## 计划入口

`lzheng-fitness-plan` 在用户目标明确为增肌、体态重组或保持训练表现的减脂期时，可按问题读取本项目：

- 训练变量、力竭、活动范围、休息与动作取舍：M04、M05 与 04-训练变量的增肌取舍；
- 高级方法：M06 与 05-高级方法的成本收益；
- 并行有氧：M07 与 06-有氧与增肌并行；
- 计划结构：M09 与 08-最大化增肌的计划设计；
- 营养原则：M10、M11 与 09-增肌营养的优先级。

## 复盘入口

`lzheng-strength-training-review` 只能把本项目用于解释训练变量与趋势：

- 表现/体型变化是否有足够证据：03-如何测量真实肌肉增长；
- 增加训练量、频率或力竭前的取舍：04-训练变量的增肌取舍；
- 有氧、恢复或饮食是否成为限制因素：06-有氧与增肌并行、08-最大化增肌的计划设计、09-增肌营养的优先级。

## 不变的职责边界

- 计划 Skill 先读取用户确认、Notion 与当前执行基准；本专家不覆盖动态事实；
- 两个 Skill 仍负责安全筛查、信息不足追问、个体动作选择和最终处方；
- 用户输出只呈现必要的来源说明、分析与结论，不显示本项目文件路径或路由 ID；
- 使用本书时应注明它是 2021 年第二版；需要最新安全或医学结论时必须联网核验更高优先级来源。
