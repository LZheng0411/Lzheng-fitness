# 边界与冲突处理

| 情境 | 处理 |
| --- | --- |
| 医疗、疾病、药物、孕期、未成年、进食障碍风险 | 不用本书给处方；转交合格专业人员并核验当前指南。 |
| 2022 年后的补剂安全、营养指南或作者观点 | 不能用本书声称“最新”；联网核验高优先级来源。 |
| 训练变量与营养变量交叉 | Alan 先判断能量、宏量、依从性与补给；Brad/Eric/Greg 只在各自训练变量内补充；Lzheng 最终整合。 |
| 减脂平台 | 先核对 2–4 周趋势、执行度、NEAT/活动变化与记录误差；不能先归咎于“代谢损坏”。 |
| 补剂需求 | 先看目标、基础饮食、训练和睡眠；补剂不替代能量、蛋白与训练执行。 |
| 精确热量/宏量 | 必须来自当前事实和趋势；本书的公式是起点，不是跨人群固定答案。 |

所有用户可见回答都应说明“本书 2022 年观点”的适用前提；内部路由和文件路径不展示。
