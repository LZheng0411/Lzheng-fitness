# 营养决策框架

## 来源直接观点

对一般体成分目标，书中的编程顺序是：目标与期限 → 热量 → 蛋白 → 脂肪 → 剩余碳水；以运动表现为第一目标时，先满足碳水再放脂肪。灵活控制不是“什么都不管”，而是在营养密度为主体的前提下，为偏好食物预留空间（第 1、8、9 章）。

## Lzheng 的结构化应用

```text
安全与专业边界
→ 明确目标、期限与当前 2–4 周趋势
→ 估算热量起点，设定观察周期
→ 先保证蛋白和纤维/食物质量底盘
→ 按训练需求或偏好分配碳水与脂肪
→ 检查是否能持续执行，再考虑时机、餐次和补剂
→ 用体重趋势、围度/表现、饥饿与执行度调整
```

热量公式和宏量区间只可作为起点，必须由连续趋势校正；不要把任何单日体重、水分波动或 App 估算当成结论。

## 信息门槛

至少需要：目标与期限、体重及 2–4 周趋势、身高/大致体成分或目标体重、训练类型与每周时长、日常活动、饮食模式、目前摄入/最大障碍、疾病/用药/进食障碍风险。缺少趋势时，只能给保守起点与记录方案。

## 边界

本框架不提供医学营养治疗；糖尿病、肾病、消化吸收疾病、妊娠、未成年、进食障碍风险或异常症状必须优先由合格医疗/营养专业人员判断。
