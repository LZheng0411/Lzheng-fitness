## 真实入口代表题

| 场景 | 应走的路由 | 验收点 |
| --- | --- | --- |
| 增肌但体重不动 | N07 | 先检查趋势、训练/活动和当前摄入，不直接加固定热量 |
| 减脂总暴食 | N01、N08 | 处理僵化规则、食物环境和可持续结构，不道德化食物 |
| 力量训练者蛋白该吃多少 | N03 | 先收集体重、目标与能量状态，再给范围 |
| 想极低碳减脂 | N04 | 区分减脂依从性与高强度表现/增肌代价 |
| 咖啡因与燃脂产品 | N06 | 区分性能补剂与减脂核心，核对耐受与安全边界 |
| 训练后必须喝蛋白吗 | N11 | 把时机置于全天总量之后，识别空腹/两练例外 |
| 两个月体重平台 | N09 | 先核验执行度与新平衡，不诊断代谢损伤 |
| 想停止记录饮食 | N10 | 仅在维持阶段、风险合适时渐退，并保留观察 |
