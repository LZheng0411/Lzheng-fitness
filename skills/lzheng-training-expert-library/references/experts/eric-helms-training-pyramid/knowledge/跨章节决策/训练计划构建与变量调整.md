# 训练计划构建与变量调整

## 从问题到行动的闭环

```text
目标与现实限制
→ 依从性设计
→ VIF 起点
→ 渐进方案
→ 动作与训练日组织
→ 执行记录
→ 中周期复查
→ 维持 / 加量 / 减载 / 重组
```

## 决策规则

| 结果 | 解释 | 下一步 |
| --- | --- | --- |
| 计划未完成 | 依从性或现实约束不匹配 | 降复杂度、缩短或重排；不要先改节奏 |
| 计划完成且表现稳定上升 | 当前剂量有效 | 保持并按既定渐进推进 |
| 单次表现下降 | 可能是正常疲劳或外部波动 | 记录，等待可重复趋势 |
| 真平台且基础条件有短板 | 不是训练量问题 | 修复睡眠、能量、技术、RPE/频率后重跑中周期 |
| 真平台且恢复良好 | 刺激可能不足 | 对应肌群/动作加 1–2 组 |
| 疲劳征象 2+ | 恢复被压过 | 减载；反复发生则约减 20% 总量或重组压力 |
| 长/激进减脂 | 可恢复剂量下降 | 下调一个训练量层级，固定中周期减载 |

## 记录模板

每次训练记录动作、工作组、次数、负荷、RPE/RIR、完成与否、疼痛/不适。每周补充睡眠、生活压力、饮食/体重趋势和训练兴趣。每中周期再判断表现趋势与疲劳清单。
