# 判断方法与决策树

## 证据标签

- **[原书直接规则]**：原书明确提出的优先级、建议、定义或流程，必须标 PDF 页码。
- **[AI 结构化推导]**：把多个原书规则排成固定决策顺序，便于稳定回答；不能伪装为原书原句或固定处方。
- **[安全边界]**：本书没有授权处理的诊断、康复、医学或 2018 年后观点；停止常规处方并转交。

## 最小信息闸门

1. **[安全边界]** 有无异常疼痛、疾病、术后限制、孕期或医嘱？有则转 `R27`。
2. **[原书直接规则]** 目标与期限：力量、增肌、双项目、比赛或仅维持？
3. **[原书直接规则]** 现实约束：可训练天数、单次时长、器械、户外/其他运动与生活压力。
4. **[AI 结构化推导]** 近 2–4 周真实日志：动作、工作组、次数、负荷、RPE/RIR、完成度。
5. **[AI 结构化推导]** 恢复和趋势：睡眠、能量摄入/体重趋势、压力、训练兴趣、表现与不适变化。

缺少会改变结论的信息时，只追问该信息；不编造精确重量、组数或周期。

## 总决策树

```text
安全/范围检查
  ├─ 命中医疗、疼痛诊断、术后或特殊人群 → R27：声明边界并转交
  └─ 常规训练问题
       ├─ R24/R25：先确认版本与身份边界
       ├─ 依从性是否成立？
       │    └─ 否 → R01：先做现实、享受、灵活的最小可执行版本
       ├─ VIF 是否与目标、训练年龄、恢复匹配？
       │    └─ 否 → R02/R03/R04/R05：重组变量，不先换动作
       ├─ 是否有可重复的进步？
       │    ├─ 有 → 保持既定渐进；不因单次波动乱改
       │    └─ 无 → R07：平台期分流
       │          ├─ 基础条件未满足 → 修复后重跑中周期
       │          ├─ 疲劳高 → R09/R08：减载或先减量
       │          └─ 恢复良好且真停滞 → 最小加量实验
       └─ 仅当上游通过，才进入动作、休息、密度、节奏细节
```

## 平台期分流

1. **[原书直接规则] 暂时波动**：一两次表现差、陌生器械、单晚低睡眠或临时压力，不判平台（PDF p. 102–103、121）。
2. **[AI 结构化推导] 基础排查**：检查技术、RPE 估计、训练完成度、睡眠、能量、压力、目标肌群/动作频率与动作重叠。
3. **[原书直接规则] 恢复差**：疲劳信号累积时优先减载；反复过早疲劳时审查总量和训练组织（PDF p. 121–125）。
4. **[原书直接规则] 恢复良好的真平台**：只给停滞肌群或动作增加最小训练量，通常先加 1–2 组（PDF p. 124–126）。
5. **[安全边界]** 疼痛不能由这棵树诊断成“弱点”或“过度训练”。

## 多意图规则

示例：“卧推卡住，要不要换动作？”

```text
主路由：R07 平台期
辅助路由：R02 训练量、R03 强度/RPE、R05 频率、R20 自动调节
下游路由：R12 动作选择、R13 弱点与卡点
```

先完成主路由的上游排查，才讨论下游替换；不得把“换动作”作为默认答案。
