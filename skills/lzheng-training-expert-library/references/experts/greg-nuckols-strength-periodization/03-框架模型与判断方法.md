# 框架模型与判断方法

## 模型一：力量表现的四层来源

```text
力量表现
├─ 肌肉量与组织能力：决定可用的长期能力上限
├─ 动作专项技能：决定是否能把能力表达在目标动作/规则下
├─ 可训练与可恢复容量：决定能否持续积累有效刺激
└─ 关节健康、时间与比赛技能：决定长期可持续性和峰值表达
```

这是对 Complete Guide 的结构化转述。它不是诊断公式：训练者应先问“当前哪一层最限制目标动作”，而不是同时追求全部变量。

## 模型二：训练量实验

```text
稳定目标与动作 → 记录当前剂量和结果 → 小幅改变一个变量
→ 观察足够长的表现、体型、疲劳与依从性 → 保留、回退或换假设
```

训练量是输入，不是成效本身。有效的观察至少要区分：目标肌群或动作、接近力竭程度、动作是否改变、训练频率、恢复/饮食和观察周期。缺少这些条件时，“我加量没用”不是可解释的结论。

## 模型三：专项性连续体

距离重要测试/比赛越近，主项动作、负荷、规则和技能暴露通常应越接近目标；距离越远，越可以用较低关节代价的变式和肌肥大训练建立资源。连续体不是强制线性日历，而是由目标期限、技术需求、组织耐受和既往反应共同决定。

## 模型四：变更优先级

1. 先确认目标、动作标准、记录质量和恢复约束；
2. 再判断是否真的停滞，而非一天波动或测试条件变化；
3. 优先调整最能解释限制的变量；
4. 一次主要测试一个改变，并预先写好保持/回退条件；
5. 只有比赛临近或目标改变时，系统性改变专项性与疲劳管理。

## 来源层次

- **原文直接观点**：力量受肌肉、技能、健康/长期因素影响；训练量和频率需要个体化；周期化的优势与机制不能被夸大。
- **结构化推导**：上述四个模型把多篇文章的决策顺序合并，便于 Lzheng 系统调用。
- **超出范围**：任何具体周数、每周组数、重量或动作处方都必须由当前训练事实和职责 Skill 决定。
