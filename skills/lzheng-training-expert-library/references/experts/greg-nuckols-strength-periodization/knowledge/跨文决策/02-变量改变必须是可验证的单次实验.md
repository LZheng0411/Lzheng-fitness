# 变量改变必须是可验证的单次实验

## 要解决的取舍

平台或表现不好时，应该加量、加频率、换周期、改动作还是直接减载？

## 跨文结论

这些变量都可能有用，但同时大改会摧毁反馈。先确认是否真实停滞与恢复问题，再优先选择最符合当前瓶颈的一个主要变量，并提前规定评价条件。

## 决策树

```text
记录不足/测试条件变了 → 先补记录，不改处方
单次波动或短期疲劳 → 自动调节/维持，继续观察
主项技术不稳定或单次量过满 → 在总量近似下调整频率/练习分布
目标肌群或工作容量不足且恢复良好 → 小幅加量或做局部专项块
比赛日期临近 → 提高专项性、管理疲劳、必要时峰值
目标/规则/生活条件改变 → 重写阶段方向，不只调一个数字
```

## 记录与调整条件

每次实验至少写清：目标变量、保持不变的变量、起点、观察时长、表现/体型/恢复指标，以及何时停止。若恢复和动作质量先恶化，不能因“还没到目标组数”继续硬加。

## 版本处理

*More is More* 与 *DUP Revisited* 可帮助理解早期论证，但训练量的剂量与个体化判断以 2025 主文为准；周期化模型以具体目标与研究边界解释，不以方案名称取胜。
