# 从缺口到最小纠正：运动模式、质量与回退

## 解决的问题

训练者最喜欢重复自己擅长的动作。Dan John 的贡献是把注意力转到“长期没练、做不了或做了会明显失控的东西”，再以最小、可验证的方式补回去。

## 核心命题

*Intervention* 用推、拉、髋铰链、深蹲、负重行走与第六动作（滚动、跪姿、单腿等）的框架检查空白；它把 Turkish get-up 作为协调性观察工具，并强调基础动作质量、重复评估和“不要给失功能加速度”（PDF 90—101、103—178）。

这是一张**训练审计表**，不是每周动作配额表。真正的干预应满足：缺口与目标相关、动作可安全教学、投入可恢复、能在下一轮记录中验证。

## 最小纠正路径

```text
发现缺口
→ 核查：是训练没安排、不会做、场地限制，还是疼痛/医学问题？
→ 医学问题：安全分流
→ 非医学、可教：选择一个低学习成本的替代或回退动作
→ 保留原计划主线，只替换/加入最少必要量
→ 以动作标准、RPE、完成度和主项质量复核
→ 通过后再增加难度、速度或负荷
```

## 可执行判断

- 训练很完整但主项持续不稳：先检查动作标准、休息、恢复和近期暴露，不直接判定“缺一个动作”。
- 明显偏科且与目标相关：把缺口放进热身、低疲劳辅助或独立技术段；先让训练者获得稳定成功样本。
- 想加速度、爆发或更高难变式：先确认基础模式可控。速度会放大已有错误，不能拿它做纠正工具。
- 回到基础不是退步：当动作质量、可恢复性或训练连续性不足时，它是为后续进阶腾出空间。

## 容易误用

书中力量“标准”来自作者的教练经验，只能提示继续问什么，不能诊断功能、预测受伤或压成普遍门槛。Turkish get-up、负重行走、深蹲或髋铰链都不是对每个人的强制动作；器械、动作替代与训练量仍需按目标和安全条件选择。
