# Dan John 训练干预与 Easy Strength

这不是一套固定的“Dan John 计划”。它服务于一个更上游的问题：在改变训练变量之前，先判断训练者的目标、当前状态、缺口和生活条件是否允许那项改变；随后用可重复的基础工作积累长期能力。

## 从这里开始

1. 先诊断再干预：目标含糊、反复中断、卡住时先读。
2. 从缺口到最小纠正：处理明显偏科、动作质量或回退问题。
3. 长期训练模式：判断长期基础与短期冲刺。
4. Easy Strength：判断低疲劳、重复练习是否适合当前阶段。
