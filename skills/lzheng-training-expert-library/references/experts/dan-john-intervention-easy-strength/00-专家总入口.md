这是基于 Dan John 的两本书整理的来源限定内部知识模块，不模拟 Dan John 本人，也不代表两本书出版后的观点。

## 立项契约

| 项目 | 已冻结决定 |
| --- | --- |
| 专家/方法 | Dan John；先定位 Point A、识别缺口并作针对性干预，再以低摩擦、可重复的力量练习长期推进 |
| 主源与顺序 | 《Intervention》（2013）是判断和干预主源；《Easy Strength Omnibook》（2022）补充长期力量发展与训练哲学 |
| 负责变量 | 目标是否清楚且可持续、训练是否存在明显运动模式/能力缺口、何时回到基础、长期训练应以何种负担运行、何时才适合短期冲刺 |
| 排除范围 | 当前训练事实与精确重量处方、医学/康复/疼痛诊断、营养处方、肌肥大剂量与周期化的最终裁决、作者出版后观点 |
| 当前事实所有者 | 用户当次确认、Notion 当前记录、当前执行基准与 Lzheng 训练 Skill |
| 最终决策所有者 | `lzheng-fitness-plan`、`lzheng-strength-cycle-planner`、`lzheng-strength-training-review`、`lzheng-training-return` |
| 用户输出 | 由主 Skill 输出详细分析、结论、行动与必要来源；默认隐藏工程路由 |
| 自动触发 | 未要求；不建立独立聊天入口 |
| 验收入口 | 完整计划、单项周期、训练复盘、训练接回四个 Lzheng Skill |

## 固定读取顺序

1. 先读 内部问题映射，确认是否真的命中 Dan John 的独立变量；
2. 读取主知识卡；涉及取舍时再读 框架模型与判断方法；
3. 回到 来源档 指向的规范检索稿核对章节、PDF 页码或 EPUB 章节；
4. 只把来源限定的判断交给拥有当前事实的 Lzheng Skill，不覆盖当前计划、体重、疼痛信息或动态训练记录。
