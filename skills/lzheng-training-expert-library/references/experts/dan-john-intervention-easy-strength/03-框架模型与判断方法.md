# 框架模型与判断方法

## 一、先诊断，再干预

**原书直接观点**：`Intervention` 用“十个问题 + 五项原则”协助找到 Point A 并走向 Point B。核心不是挑一个万能计划，而是先确认目标、健康/健身边界、生活可持续性、年龄与训练史、现有动作和缺口。

**结构化推导**：Lzheng 应把它落实为“先证实当前问题是否真的来自训练缺口，再改变一个最小变量”的判断次序，而不是把“需要更努力”当作默认答案。

```text
目标是否明确、属于可由训练解决的问题？
  否 → 澄清目标，或转安全/医疗/营养/技术流程
  是 → 当前事实和动作质量是否足以确定 Point A？
       否 → 先补记录、视频/动作描述或做保守基准
       是 → 是否有重复出现的模式、能力或执行缺口？
            是 → 用最小可验证纠正先补缺口
            否 → 再由目标对应专家判断量、强度、频率或周期
```

## 二、训练的缺口优先于最擅长的项目

**原书直接观点**：该书把推、拉、髋铰链、深蹲、负重行走及“第六动作”（滚动、跪姿、单腿等）作为检查训练是否明显偏科的镜头；它建议找出忽略的动作，而不是重复擅长项目。

**适用限制**：这不是要求每个人在每周都机械塞进六类动作，更不是用书内力量数字诊断身体。只在动作可安全教学、缺口确实会影响目标或长期可训练性时，才把它变成方案优先项。

## 三、Park Bench 与 Bus Bench

**原书直接观点**：长期多数时间应处于可重复的 Park Bench 工作；Bus Bench 是有明确终点、短期集中、可预期恢复代价的冲刺。二者不是好/坏之分，但不能全年都当 Bus Bench。

**结构化推导**：专项周期只有同时满足“明确测试/比赛或短期目标、基础执行稳定、恢复资源足够、结束和回归计划清楚”时才升级为 Bus Bench；否则优先维持或重建 Park Bench。

## 四、Easy Strength 的低疲劳练习逻辑

**原书直接观点**：书中以“连续约 40 次训练、重复少数动作、不漏次数、不接近挣扎、感觉轻再加重量”说明一种通过高质量重复和低疲劳累积力量的做法；也强调频率、动作数、变化要随人和情境调整。

**不能推导为**：每个人必须每周五练、每次五动作、固定做 40 次，或以“不累”掩盖没有足够刺激。具体组次、RPE、容量与周期由 Lzheng 结合 Helms、Greg、Brad、当前训练事实决定。
