# Asset notice

The workbench ships with maintainer-approved PNG, WebP and MP4 background files under `skills/lzheng-fitness-workbench-builder/assets/backgrounds/`.

The repository maintainer has authorized their inclusion in this package and in workbenches generated by its initialization script. The v3.5.0 default uses the same background set as the maintainer's approved personal workbench: a PNG source, WebP static fallback, desktop MP4 and mobile MP4. Their SHA-256 values are recorded in `assets/presentation-provenance.json` inside the builder Skill. Do not replace these files with third-party assets unless you hold the corresponding distribution rights. The files contain no personal training data.

End users may replace generated-workbench backgrounds with `Replace-FitnessWorkbenchBackground.py`. They are responsible for the usage and distribution rights of supplied images and videos; custom user assets must not be committed to the public repository without explicit authorization.
