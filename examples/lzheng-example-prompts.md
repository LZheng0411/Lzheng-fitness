# Lzheng Fitness 示例任务

以下示例不包含真实用户数据。

## 个性化计划

```text
使用 $lzheng-fitness-plan。我的目标是增肌和基础力量，每周可以训练四次，每次 75 分钟，有商业健身房器械。请先完成最少必要问诊，再生成状态快照、训练计划 JSON 和单文件 HTML。
```

## 中断接回

```text
使用 $lzheng-training-return。我停训了 14 天，之前每周三练，现在只有 30 分钟。请先判断恢复权限，再给正常、降级、最低三档任务和七天接回卡。
```

## 单项周期

```text
使用 $lzheng-strength-cycle-planner。请根据我最近三次卧推记录制定 8 周周期，写清顶组、回退组、未完成分支、减量和测试，并生成带曲线的 HTML。
```

## 训练复盘

```text
使用 $lzheng-strength-training-review。我没有多周周期，下面是最近三次同标准深蹲记录。请判断我的渐进方式是否合适，给出下一次处方并保存复盘记录。
```
